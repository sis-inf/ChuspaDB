# Telemetría de uso
> **No implementado.** Esta funcionalidad está planificada pero aún no existe en el código del proyecto. Ver [roadmap.md](roadmap.md).
## ¿Qué es la telemetría?

La telemetría de uso será una funcionalidad opcional que permitirá recopilar información sobre el uso de las funcionalidades de la aplicación. Su objetivo será ayudar a identificar qué características son utilizadas con mayor frecuencia para mejorar el proyecto.

## Información que se recopila

Cuando la telemetría está habilitada, únicamente se recopilarán datos relacionados con el uso de las funcionalidades de la aplicación, por ejemplo:

- Uso de determinadas funcionalidades.
- Frecuencia de utilización de características.
- Eventos relacionados con el funcionamiento de la aplicación.

## Información que NO se recopila

La telemetría **no** recopilará:

- Datos de conexión.
- Consultas realizadas por el usuario.
- Resultados obtenidos por el usuario.
- Información personal o sensible.

## Telemetría opcional (Opt-in)

La telemetría será completamente **opt-in**, lo que significa que estará deshabilitada por defecto y solo se activará cuando el usuario decida habilitarla de forma explícita.

## Objetivo

La información recopilada se utilizará únicamente para comprender el uso de las funcionalidades y orientar futuras mejoras del proyecto, respetando la privacidad de los usuarios.
